# demo-case/

Data for the sepsis proof of concept.

| File | What it is | Where it comes from |
| --- | --- | --- |
| `sepsis-case.json` | Start vitals, admission labs, the precomputed trajectory tree, and the real patient's course | Generated by `engine/build_case.py` from the **open-access** MIMIC-IV Clinical Database Demo v2.2 |
| `content.ts` | Case story, questions and answers, orders, teaching points | Written by the team. Not real patient data. Needs review by a medical student. |
| `LICENSE-ODbL.txt` | The Open Database License that covers the demo data | Copied from the demo dataset |

## Data license

`sepsis-case.json` contains information from the
[MIMIC-IV Clinical Database Demo](https://physionet.org/content/mimic-iv-demo/2.2/),
which is made available here under the
[Open Database License (ODbL) v1.0](https://opendatacommons.org/licenses/odbl/1-0/).
This derived database is shared under the same license.

Cite: Johnson, A., Bulgarelli, L., Pollard, T., Horng, S., Celi, L. A., & Mark, R. (2023).
MIMIC-IV Clinical Database Demo (version 2.2). PhysioNet. https://physionet.org/content/mimic-iv-demo/2.2/

To rebuild it: download the demo from PhysioNet, then

```bash
cd engine
pip install -r requirements.txt
python build_case.py <path to mimic-iv-clinical-database-demo-2.2> ../web/src/demo-case/sepsis-case.json
```

**Only the open-access demo is allowed here.** Credentialed MIMIC-IV data, or anything
derived from it, must never be committed: this repo is public and that data is covered
by the PhysioNet Data Use Agreement.
